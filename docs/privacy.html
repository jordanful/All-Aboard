Privacy Policy

Last updated: February 10, 2026

Overview

All Aboard is a simple transit tracker for the Chicago CTA. We believe in straightforward privacy: we don't collect your data, period.

Data We Collect

None. All Aboard does not collect, store, or transmit any personal data. There are no user accounts, no analytics, no tracking, and no server or database.

Location Data

All Aboard requests access to your device's location to find the nearest bus stop or train station. Your location is used entirely on-device and is sent only to the CTA's public API to retrieve nearby arrival predictions. Your location is never stored, logged, or sent anywhere else.

Recently Viewed Routes

The app stores your recently viewed routes locally on your device using AsyncStorage. This data never leaves your device and is not accessible to us or any third party.

Third-Party Services

All Aboard communicates with the following public CTA APIs to provide transit data:

  • CTA Bus Tracker API
  • CTA Train Tracker API
  • CTA Customer Alerts API

These are public APIs operated by the Chicago Transit Authority. Please refer to the CTA's privacy policy for information about how they handle API requests.

Children's Privacy

All Aboard does not collect any data from anyone, including children under 13.

Changes

If this policy changes, we will update this page with the new date.
